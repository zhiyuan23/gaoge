# 高歌 Brand 导航与能力弹窗修订设计

## 背景

`apps/brand` 首页与 Group 页已完成第一轮 Apple 风格交互优化，但实际预览后需要进一步统一弹窗位置、精简首页媒体控制，并让 Group 桌面导航与首页保持相同的能力说明行为。Group 顶部导航也需要在现有暗色背景上增强毛玻璃透明感，同时保持文字可读性。

本文是对 `2026-08-08-gaoge-brand-apple-interaction-optimization-design.md` 的定向修订。若两份文档存在冲突，以本文关于能力弹窗、首页右侧入口和 Group 导航的要求为准；原设计中其余 Group 间距、静态卡片反馈、系统偏好和无障碍要求继续有效。

## 目标

- 桌面和移动端都使用屏幕水平、垂直居中的能力弹窗。
- 点击弹窗面板以外的任意区域都能可靠关闭弹窗。
- 移除首页背景视频播放控制，保留现有自动播放与减少动态效果行为。
- 首页集团入口统一显示为“高歌集团”。
- Group 桌面导航宽度与 `max-w-7xl` 主题内容区域一致。
- Group 桌面领域项与首页一样打开能力弹窗，不再直接跳转正式页面或体育外站。
- Group sticky 导航使用可感知但克制的中等透明毛玻璃材质。

## 不在范围内

- 不移除或暂停首页背景视频本身。
- 不改变首页和 Group 页四个能力领域的标题、状态和说明文案。
- 不修改 `/digital`、`/content`、`/group` 路由或体育站点地址。
- 不给 Group 移动端增加四个领域按钮。
- 不新增弹窗拖拽、手势关闭、自动轮播或新的导航层级。
- 不新增依赖，不修改 `apps/sports`、API、CMS、部署和数据模型。

## 能力弹窗

### 统一居中布局

桌面和移动端都使用同一套居中 modal 布局：

- 外层占满视口并水平、垂直居中面板。
- 桌面最大宽度继续保持约 672px。
- 移动端左右保留 16px 安全边距，不再贴近底部。
- 面板最大高度不超过视口可用高度；内容超出时仅面板内部滚动。
- 移除 `isMobile` 布局状态、触发按钮位置测量、动态 `transform-origin` 和底部 Sheet 样式。

### 外部区域关闭

继续保留原生 `<dialog>` 及现有无障碍行为：

- 打开后焦点进入关闭按钮。
- Escape、关闭按钮和弹窗外部区域都可以关闭。
- 关闭完成后焦点返回最后一个触发按钮。
- 弹窗内部领域切换继续保持可操作和可打断。

弹窗外部关闭使用明确的事件边界：外层居中容器接收点击并请求关闭，面板自身阻止点击冒泡。现有遮罩只负责背景调暗和透明度动画，不依赖一个难以命中的独立按钮区域。这样点击面板四周、上下留白或移动端侧边空隙都具有一致结果。

### 动效

能力弹窗属于低频 modal，动效目的为防止状态突变，而不是表达触发源方向。使用现有 Framer Motion：

- 属性只使用 `opacity` 和完整 `transform` 字符串。
- 面板在屏幕中心以 `scale(0.96)` 和透明度进入，退出沿相同路径返回。
- 使用 250ms 强 `ease-out`，不增加弹跳。
- 遮罩继续使用约 180ms 的透明度变化。
- `activeArea` 与 `isPresented` 继续分离，关闭过程中重新打开或切换领域仍能从当前屏幕值重定向。
- 减少动态效果时取消缩放，只保留即时或极短透明度反馈。

## 首页导航

首页右侧只保留集团入口：

- 删除暂停/播放按钮和 `lucide-react` 的 `Pause`、`Play` 使用。
- 删除 `BrandMediaControl`、`SkiingNavbar` 的视频控制 props，以及只为导航展示而维护的播放状态。
- `SkiingHero` 继续保留视频自动播放、微信环境重试、首触摸重试和播放失败静默处理。
- 集团入口的可见文字、`aria-label` 和 `title` 全部改为“高歌集团”。
- 320px 起保持单行，不再区分“认识高歌集团”和紧凑“集团”两套文案。

## Group 导航

### 宽度与布局

Group sticky header 和胶囊导航结构保持不变。桌面导航最大宽度从 `max-w-[1440px]` 改为 `max-w-7xl`，与 Group 主体模块的内容宽度一致。移动端继续显示首页入口和当前“集团”状态。

### 领域行为

Group 桌面的数字、内容、影视和体育全部渲染为能力按钮：

| 领域 | 行为                     |
| ---- | ------------------------ |
| 数字 | 打开数字能力弹窗         |
| 内容 | 打开内容能力弹窗         |
| 影视 | 打开影视能力弹窗         |
| 体育 | 打开体育能力弹窗         |
| 集团 | 保持 `aria-current=page` |

四个按钮使用与首页顶部领域按钮相同的 `aria-controls`、`aria-expanded` 和 `aria-haspopup="dialog"` 语义，并把当前按钮保存为焦点归还目标。Group 导航不再为数字、内容和体育执行路由或外站跳转；正式页面路由和体育站点本身保持不变，仍可通过直接地址及项目内其他既有入口访问。

### 毛玻璃材质

推荐并采用中等透明毛玻璃，而不是高透明或近实色方案：

- 背景使用约 `rgb(10 10 12 / 55%)` 的深色透明层。
- 使用约 24px 的背景模糊和轻微饱和增强。
- 保留 `white/15` 左右的边框、顶部内高光和柔和投影。
- 不叠加第二层浅色玻璃，不增加硬分隔线。
- 文字保持不低于现有导航对比度；当前集团状态继续使用更实的选中表面。

该材质适合 Group 页的复杂暗色图像背景：它允许背景轻微透出，能够表达 sticky chrome 的悬浮层级，同时不会像高透明方案一样让文字随背景明暗波动。

系统偏好继续覆盖默认材质：

- `prefers-reduced-transparency: reduce` 使用近实色深色背景并移除模糊。
- `prefers-contrast: more` 使用近实色背景、更明显边框和 2px 焦点轮廓。

## 组件与文件边界

- `BrandNavigation.tsx`：移除媒体控制接口和触发源测量；统一居中弹窗；Group 领域项改为能力按钮；导航宽度和文案更新。
- `SkiingNavbar.tsx`：恢复为只转发 `BrandNavigationHandle` 的轻量包装。
- `SkiingHero.tsx`：移除视频播放状态和切换回调，保留自动播放与海报逻辑。
- `styles.css`：移除移动端底部 Sheet 和动态 origin 样式，新增统一居中 modal 与 Group 中等透明毛玻璃材质。
- `BrandPageShell.tsx`：保留 Group 的 `overflow-x-clip`，确保 sticky 导航相对视口生效。
- 不新增 context、全局状态、共享包或依赖。

## 测试与验证

自动化测试覆盖：

- 首页不再渲染“暂停背景视频”或“播放背景视频”。
- 首页集团入口的可见文字和无障碍名称均为“高歌集团”，目标仍为 `/group`。
- 桌面和移动端弹窗容器都使用居中布局，不再包含底部对齐类或移动端位移目标。
- 点击关闭按钮、Escape 和弹窗面板外区域都能关闭并归还焦点。
- 点击弹窗面板内部不会误关闭。
- Group 导航使用 `max-w-7xl`，并保持 sticky。
- Group 数字、内容、影视、体育均为能力按钮且不再是导航链接。
- Group 四个按钮能打开对应内容并在关闭后恢复焦点。
- 现有四个能力内容、Group 页面数据、管理层和董事会数量保持不变。

- 键盘打开、切换、Escape 关闭和焦点归还正确。
- 控制台无新增 warning 或 error。

## 成功标准

- 所有尺寸的能力弹窗视觉中心一致，不再在移动端呈现底部 Sheet。
- 点击面板外任意可见遮罩区域均能关闭，点击面板内部不会误关闭。
- 首页导航更精简，只保留明确的“高歌集团”入口。
- Group 桌面领域行为与首页一致，用户不会在相似导航项之间遇到不同结果。
- Group 导航宽度与主体内容对齐，毛玻璃透明度可感知且文字稳定可读。
- 减少动态、减少透明度和增强对比度三类系统偏好继续有效。
