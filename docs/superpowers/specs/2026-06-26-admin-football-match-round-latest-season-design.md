# 足球比赛信息默认赛季

## 目标

足球后台的比赛信息列表首次进入时，赛季筛选框默认选择当前默认年度内最新一场比赛的赛季。新增比赛的预填逻辑继续基于同一条最新比赛，不依赖已被筛选的表格首行。

## 范围

- 仅修改 `apps/admin` 的足球比赛信息页面。
- 保留现有默认年度 `2026` 和接口既有的排序规则：比赛日期倒序、创建时间倒序。
- 不新增后端接口，不修改篮球模块。

## 数据流

1. 页面初始化时，以默认年度查询一条最新比赛记录。
2. 将该记录保存为新增比赛的 `previousMatchRound`，并将其赛季写入列表搜索状态。
3. 以该筛选状态请求并展示列表；没有比赛时赛季保持为空。
4. 新增或删除成功后重新查询最新比赛。若用户仍使用页面默认筛选状态，同步赛季并刷新列表；用户手动修改过筛选条件时，不覆盖其选择。

## 错误处理

复用现有请求异常处理。最新比赛查询未返回记录时，新增表单沿用无历史比赛的默认值，赛季筛选保持“全部”。

## 验证

- 有比赛时，首次加载的赛季等于最新比赛的赛季，列表请求带该赛季。
- 新增比赛使用同一条最新比赛预填赛季、场次和日期。
- 没有比赛时，赛季为空且新增比赛仍可使用基础默认值。
- 用户手动筛选后，新增或删除不会重置其筛选。
