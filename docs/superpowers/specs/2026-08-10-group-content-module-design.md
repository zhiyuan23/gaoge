# Group 页高歌内容模块设计

## 背景

Group 页首屏已经展示高歌数字、高歌内容、高歌影视和高歌体育四个业务方向，但正文目前只有高歌数字和高歌体育的独立业务模块。高歌内容缺少与其业务定位相匹配的正文表达。

本次在 Group 页增加一段简洁的高歌内容模块。模块不复制 Content 页的完整叙事，只用一张卡片介绍理念并概括四项能力，同时提供进入 `/content` 的站内入口。

## 已确认方向

- 采用 A 方案“宣言主导”。
- 模块位于高歌数字之后、高歌体育之前。
- 页面顺序形成“数字 → 内容 → 体育”。
- 模块只使用一张横向大卡片。
- 卡片以理念文案为主，能力名称作为底部简洁索引。
- 整张卡片链接到 `/content`。

## 内容结构

模块标题区：

> 以内容连接热爱
>
> 高歌内容

卡片正文：

> GAOGE CONTENT
>
> 让每一份热爱  
> 持续被看见。
>
> 以内容与运营连接品牌、平台和真实社群。

卡片底部展示四项能力：

- 内容策略
- 内容创作
- 全平台运营
- 社群连接

## 页面与导航

- 新模块使用章节 ID `group-content`。
- 桌面导航顺序调整为“概览 / 数字 / 内容 / 体育 / 管理层 / 董事会 / 愿景”。
- 移动导航顺序调整为“概览 / 数字 / 内容 / 体育 / 集团”。
- Group 页组件顺序调整为 `GroupHero`、`DigitalStructure`、`ContentStructure`、`SportsStructure`，其余集团治理与愿景模块保持不变。

## 视觉设计

- 延续 Group 页深绿色背景、暖白文字和现有圆角系统。
- 模块标题区继续使用 Group 页统一的眉题、标题和留白尺度。
- 卡片使用深色表面和克制的深酒红光影，建立高歌内容的独立识别。
- 不使用图片、平台图标、案例封面、数据或多张能力卡片。
- 理念文案为主要视觉焦点；四项能力只在底部横向排列，移动端允许自然换行。
- 右上角使用现有箭头图标表达站内进入关系。

## 交互与可访问性

- 整张卡片使用 React Router 的 `Link` 跳转到 `/content`，不打开新窗口。
- 链接具有明确的可访问名称。
- 保留现有 hover、focus-visible 和 active 反馈语言。
- 模块整体继续由 `GroupSectionReveal` 控制进入效果，并遵守减少动态设置。
- 标题层级与现有数字、体育模块一致。

## 数据与组件

- 新增 `GroupContentOverview` 数据类型，包含理念说明、四项能力和固定站内路径。
- 在 Group 数据文件中维护单个 `groupContentOverview` 对象。
- 新增 `ContentStructure` 组件，负责模块标题区和单张理念卡片。
- 不直接依赖 Content 页内部组件，避免 Group 页面与 Content 页面表现层耦合。
- 不新增 API、CMS、依赖或跨应用共享包。

## 测试与验收

- Group 页在高歌数字之后、高歌体育之前渲染高歌内容模块。
- 页面出现确认的三段理念文案和四项能力。
- 整张卡片链接到 `/content`，且不使用新窗口。
- 桌面与移动章节导航都包含“内容”。
- 桌面、平板和手机视口无横向溢出或文字裁切。
- 现有 Group 页面进入动画、元数据、数字、体育及治理模块不受影响。
- Brand 应用格式、Lint、类型检查、测试和生产构建通过。
