# 高歌 Brand 首页与 Group 页 Apple 交互优化设计

## 背景

`apps/brand` 的首页已经形成沉浸式滑雪品牌封面，`/group` 也已经完成集团事业部、体育、管理层、联赛董事会和集团愿景的公开表达。当前页面的主要问题不是视觉方向不足，而是相似元素在不同页面具有不同交互能力、能力弹层缺少触发源空间关系、Group 长页滚动后失去导航，以及部分持续动效、低对比文字和玻璃材质缺少完整的无障碍降级。

本次在现有暗色视觉体系、品牌文案、路由和静态数据基础上做一次平衡优化。目标是让界面更可预测、更直接、更容易理解，同时保持现有首页构图和 Group 页内容结构。

## 目标

- 统一首页、正式品牌页和 Group 页的品牌领域导航行为。
- 让 Group 页导航在长页滚动中持续提供位置感和返回路径。
- 让首页能力弹层从触发源自然出现，并在关闭或切换过程中保持可重定向。
- 收紧 Group 页纵向节奏，消除非交互卡片的错误点击暗示。
- 提升首页中文说明与集团入口的发现性和动态背景上的可读性。
- 为首页背景视频提供明确的暂停与恢复控制。
- 补齐减少动态效果、减少透明度和增强对比度三类降级。
- 保持 1440×900、390×844 和 320×800 下无横向溢出。

## 不在范围内

- 不新增 `/film` 路由或新的品牌领域页面。
- 不新增 Group 页内目录、滚动进度条或 section 自动高亮导航。
- 不修改集团、管理层、联赛董事会和愿景的静态数据或公开文案。
- 不新增体育站点深链；两张体育卡片继续进入现有体育站点首页。
- 不实现可拖拽弹层、橡皮筋边界、手势关闭或声音与触觉反馈。
- 不新增依赖，不引入新的设计系统或共享包抽象。
- 不修改 `apps/sports`、API、CMS、部署或数据模型。

## 设计原则

### 熟悉与一致

外观相同的品牌领域项必须具有一致行为。已有正式目标的领域继续作为链接；没有正式页面的影视必须明确呈现为不可进入状态，不能伪装成链接。

### 直接响应

按钮在 pointer-down 时继续提供即时缩放或颜色反馈。弹层切换和关闭不使用人工定时器锁住输入，也不在退出期间对整个弹层设置 `pointer-events: none`。

### 空间连续性

桌面能力弹层以触发按钮为视觉来源，进入与退出沿同一路径完成。移动端使用底部 sheet 语义，从底部出现并向底部退出，不从屏幕中央缩放。

### 克制

Group 页不增加第二条导航或复杂滚动指示。现有顶部胶囊导航改为浮动 sticky chrome，即可承担长页位置感。持续循环的轨道呼吸动画移除，保留首屏一次性进入动画。

## 顶部导航

### Group 页

Group 页 `header` 改为 sticky，固定在视口顶部并保留安全边距。内容滚动到其下方时，导航继续使用现有深色半透明材质、背景模糊、内高光与阴影，不新增硬分隔线。

桌面品牌领域按以下映射渲染：

| 领域 | 行为                                               |
| ---- | -------------------------------------------------- |
| 数字 | 内部链接 `/digital`                                |
| 内容 | 内部链接 `/content`                                |
| 影视 | 不可点击状态，标题和无障碍名称说明“独立页面筹备中” |
| 体育 | 外部链接 `https://sports.gaoge.cc`，新窗口打开     |
| 集团 | 当前页状态，使用 `aria-current="page"`             |

移动端继续只显示首页入口和当前“集团”状态，避免 320px 下增加横向拥挤。

### 首页

首页左侧 GAOGE 标识保持不变。右侧把现有“集团”弱标签升级为“认识高歌集团”；在不超过 384px 时显示紧凑文字“集团”，但无障碍名称始终为“认识高歌集团”。

背景视频播放时，在集团入口旁增加 44×44px 圆形暂停按钮；暂停后同一位置变为播放按钮。图标使用现有 `lucide-react`，可访问名称分别为“暂停背景视频”和“播放背景视频”。当系统请求减少动态效果、页面仅展示静态海报时不渲染该按钮。

## 首页背景与文字可读性

保持当前滑雪画面、英文主标题和四角能力信号位置。增加一层不拦截交互的局部暗色渐变，重点稳定中文说明所在的左中区域和顶部导航附近的文字对比，不把说明包进新的卡片。

中文说明保持现有内容和最大宽度，适度提高字重或文字阴影，使视频明暗变化时仍能稳定阅读。四个能力信号保留即时 `active` 缩放和至少 48px 的移动端触控高度。

## 能力弹层

### 保留能力

- 继续使用原生 `dialog` 提供 modal 语义和焦点约束。
- 打开后焦点进入关闭按钮。
- Escape、关闭按钮和遮罩均可关闭。
- 完成关闭后焦点返回最后一个触发按钮。
- 弹层内四个领域按钮继续原地切换内容。

### 状态模型

弹层把“当前内容”和“是否呈现”拆成独立状态：

- `activeArea` 保存当前能力领域。
- `isPresented` 决定面板目标是显示还是退出。
- 打开新领域时设置 `activeArea` 并把 `isPresented` 重定向为 `true`。
- 请求关闭时只把 `isPresented` 设为 `false`，不设置输入锁和关闭定时器。
- 退出动画完成且状态仍为 `false` 时，才关闭原生 `dialog` 并清空 `activeArea`。
- 如果退出过程中重新打开或切换领域，Motion 从当前屏幕值直接重定向到显示状态，不跳回初始值。

### 桌面动效

弹层打开后读取触发按钮和面板的实际位置，将面板 `transform-origin` 设置为最接近触发按钮中心的位置。面板使用无弹跳 spring：

- 类型：`spring`
- `bounce: 0`
- 响应时间：约 `0.32–0.38s`
- 属性：`opacity`、`scale` 和轻微 `y`

遮罩只做约 `0.18s` 的透明度过渡。进入和退出使用对称路径。

### 移动端动效

小于 768px 时面板贴近底部安全区，使用顶部较大的圆角并限制最大高度，内容过长时在面板内部滚动。面板从底部轻微上移进入，退出时沿原路径返回底部；不增加拖拽手势。

### 内容切换

弹层内部切换领域时不重新缩放整个面板，只对标题、状态和说明做短促交叉淡化或 4px 内的位移，避免每次切换都像重新打开 modal。

## Group 页节奏与反馈

Group 首屏结构保持不变。后续模块统一使用更紧凑的纵向节奏：

- 高歌体育：保持 `py-16 md:py-24`。
- 集团管理层：从 `py-24 md:py-32` 收紧为 `py-16 md:py-24`。
- 联赛董事会：从 `py-24 md:py-32` 收紧为 `py-16 md:py-24`。
- 集团愿景：从 `py-24 md:py-32` 收紧为 `py-16 md:py-24`。

管理层和联赛董事席位都属于只读信息：

- 移除 hover 上浮和 hover 边框增强。
- 保留材质、边框和排版，不添加光标或点击状态。
- 管理层继续使用横向人物卡；董事席位继续使用紧凑编号矩阵，二者通过尺寸和密度表达层级差异。

高歌体育两张卡片仍可点击并保留 hover、active 和 focus-visible 反馈。外链无障碍名称增加“将在新窗口打开”，图标继续作为可见外链暗示。

集团轨道的 18–22 秒无限呼吸动画移除。首屏已有 Framer Motion 一次性进入动画，足以表达结构出现，不再持续占用注意力。

## 无障碍与系统偏好

### 减少动态效果

现有 `prefers-reduced-motion` 行为继续保留：

- 首页不加载和播放背景视频，只显示静态海报。
- 弹层不做位移、缩放或 spring，只做即时状态切换或极短透明度反馈。
- Group 首屏与轨道不执行进入或循环动画。

### 减少透明度

增加 `prefers-reduced-transparency: reduce`：

- 顶部导航改为近实色深色背景并移除 `backdrop-filter`。
- 能力弹层改为近实色深色背景并移除背景模糊。
- 保持清晰边框，避免玻璃层叠导致文字失去对比。

该媒体查询浏览器支持有限，因此默认样式本身仍必须具备足够可读性。

### 增强对比度

增加 `prefers-contrast: more`：

- 导航和能力弹层背景接近实色。
- 边框不低于 `white/30` 的可见强度。
- 原本使用 `white/45–60` 的关键导航文字提升到更高对比度。
- 焦点轮廓保持 2px，并与背景形成清晰对比。

## 组件与文件边界

- `BrandNavigation.tsx`：统一 Group 导航映射，接收首页视频播放控制，管理能力弹层呈现状态和触发源位置。
- `SkiingNavbar.tsx`：把视频播放状态和切换回调传给品牌导航。
- `SkiingHero.tsx`：管理视频播放/暂停状态，提供媒体控制，并增加首页局部对比层。
- `BrandPageShell.tsx`：继续负责正式品牌页外壳和页脚，不新增页面级状态。
- `LeadershipStructure.tsx`、`LeagueBoard.tsx`、`GroupVision.tsx`：只调整纵向节奏，不改变数据接口。
- `SportsStructure.tsx`：补充新窗口无障碍提示，保留现有目标地址。
- `styles.css`：弹层桌面/移动端材质、Group 静态卡片、轨道动效移除，以及 transparency/contrast 媒体查询。
- 不新增全局状态、context、共享包或依赖。

## 测试与验证

自动化测试覆盖：

- Group 导航中的数字、内容、影视、体育分别具有正确链接或筹备中状态。
- Group 当前页状态继续具有 `aria-current="page"`。
- 首页集团入口显示明确文案，并保持 `/group` 目标。
- 背景视频暂停和恢复按钮调用真实 video 元素的 `pause()`、`play()`，并同步可访问名称。
- 请求减少动态效果时不渲染视频控制。
- 能力弹层打开、切换、关闭、Escape 和焦点归还继续有效。
- 退出过程中重新打开时取消退出目标，不需要等待人工定时器。
- 体育外链包含新窗口提示。
- 现有四个能力领域、Group 内容、三人管理层和 20 席董事会数据保持不变。

## 成功标准

- 用户滚动 Group 长页时始终能看到当前集团导航和返回首页入口。
- 相同品牌领域在不同正式页面具有一致且可预测的行为。
- 桌面能力弹层与触发按钮存在清晰空间联系，移动端明确呈现为底部 sheet。
- 快速关闭、重新打开或切换领域不会被人工定时器和输入锁阻塞。
- 首页动态背景可以由用户暂停和恢复。
- Group 长页明显更紧凑，但不改变现有内容顺序和信息完整度。
- 非交互人物与席位卡片不再提供点击式 hover 暗示。
- 三类系统偏好均有明确降级，页面在 320px 以上无横向滚动。
