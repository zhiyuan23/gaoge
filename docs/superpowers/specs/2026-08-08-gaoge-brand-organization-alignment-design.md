# 高歌品牌首页与集团页组织架构校准设计

## 背景

高歌集团的品牌与组织架构已经重新确认，但当前 `apps/brand` 首页和集团页仍沿用上一版规划：

- 首页只表达高歌数字、高歌内容和高歌体育三个方向，并保留“未来”能力入口。
- 集团页把“高歌小绿本”作为高歌内容别名，将“未来领域”作为第四个组织节点。
- 页面尚未展示高歌影视，也没有完整说明集团商业事业群的独立交付能力。
- 高歌体育尚未明确标注为非营利体育与球友社区。

本次在保留现有品牌视觉、正式路由和集团页核心交互的前提下，对公开页面的组织结构、业务定位和合作关系进行校准。

## 已确认组织架构

```text
高歌集团
├── 高歌数字    企业软件与数字化解决方案
├── 高歌内容    内容运营与视觉创作
├── 高歌影视    专业影像制作与影视作品开发
└── 高歌体育    非营利体育与球友社区
    ├── 高歌 FC
    └── 高歌超级联赛
```

四个事业群直接隶属高歌集团，不设置“商业事业群”或“非营利体育”等中间层级。高歌数字、高歌内容和高歌影视可以分别面向企业客户销售、签约和交付，也可以由集团统一协调后联合交付。高歌体育保持非营利属性。

## 目标

1. 让首页准确表达高歌集团当前四个直属事业群。
2. 让企业客户快速理解高歌能够提供的软件、内容和专业影像能力。
3. 在集团页区分企业服务板块与非营利体育板块，但不增加组织层级。
4. 明确高歌内容与高歌影视的交付边界。
5. 移除尚未进入公开架构的“小绿本”“未来领域”和独立产品品牌。
6. 保留现有品牌视觉、页面路由、董事会信息与用户正在进行的集团页调整。

## 非目标

- 不新增 `/film` 或其他高歌影视独立页面。
- 不修改高歌数字和高歌内容矩阵页的主体结构。
- 不修改高歌体育独立站点。
- 不新增独立产品品牌、客户案例或未经确认的业务数据。
- 不重新引入集团管理团队展示。
- 不改变现有 `/`、`/group`、`/digital`、`/content` 路由。
- 不对品牌站进行整体视觉重做。

## 设计读法

页面面向企业客户、合作伙伴和集团成员，延续现有暗色、克制、带有技术与运动张力的品牌语言，以清晰的组织关系和可信的服务能力为重点。

- `DESIGN_VARIANCE: 8`：保留滑雪首页的高变化度构图与集团页战略星图。
- `MOTION_INTENSITY: 5`：复用现有进入动画、能力弹窗和缓慢轨道呼吸。
- `VISUAL_DENSITY: 5`：补充业务边界与联合交付信息，但不把页面做成组织手册。

整页继续使用现有暗色主题。集团页继续使用低饱和鼠尾草绿作为唯一强调色，不增加新色系或新的视觉组件库。

## 首页调整

### 顶部领域导航

首页领域顺序统一为：

1. 数字
2. 内容
3. 影视
4. 体育

删除“未来”入口。高歌影视暂时没有独立路由：

- 在首页中作为能力按钮打开现有能力说明弹窗。
- 在数字页、内容页和集团页导航中作为无链接的事业群名称展示。
- 不使用不可点击按钮模拟链接，并通过标题说明独立页面尚未开放。

### 首页首屏

保留现有滑雪视频、静态海报、英文主张和三个既有信号的位置语言。在左上或与现有构图平衡的位置增加第四个高歌影视信号，形成：

- `DIGITAL / 企业软件`
- `CONTENT / 内容运营`
- `FILM / 专业影像`
- `SPORTS / 体育社区`

移动端四个信号使用上下两组分布，避免压住主标题、导航和品牌说明，不缩小成难以触控的装饰文字。

首页中文说明调整为同时包含企业软件、内容运营、专业影像和体育社区。页面元信息同步更新。

### 能力说明弹窗

四个事业群的公开定位如下：

| 事业群   | 状态说明                 | 简介                                                       |
| -------- | ------------------------ | ---------------------------------------------------------- |
| 高歌数字 | 企业软件与数字化解决方案 | 研发和交付企业软件、定制系统及数字化技术能力。             |
| 高歌内容 | 内容运营与视觉创作       | 承接品牌定位确定后的平台运营、图文内容和日常视觉执行。     |
| 高歌影视 | 专业影像与作品开发       | 制作企业宣传片、品牌片和专业影像，并长期开发自主影视作品。 |
| 高歌体育 | 非营利体育与球友社区     | 运营球队、内部联赛和球友社区，让体育热爱持续发生。         |

弹窗继续复用现有原生 `dialog`、焦点恢复、关闭动画和减少动态效果降级，不增加新的状态层。

## 集团页调整

### 集团首屏

保留“连接热爱，生长事业”主张和当前抽象建筑背景。辅助说明改为：集团面向企业协调技术、内容和影像能力，同时以非营利体育连接长期热爱。

### 战略星图

星图中心继续为高歌集团，四个外围节点调整为：

| 节点     | 属性               | 对外定位                   |
| -------- | ------------------ | -------------------------- |
| 高歌数字 | 企业服务           | 企业软件与数字化解决方案   |
| 高歌内容 | 企业服务           | 内容运营与视觉创作         |
| 高歌影视 | 企业服务与自主创作 | 专业影像制作与影视作品开发 |
| 高歌体育 | 非营利             | 非营利体育与球友社区       |

节点通过属性文字区分性质，不增加中间组织节点。移除“高歌小绿本”“未来领域”和未来状态样式。按照用户当前调整，四个节点继续作为只读组织信息，不在星图中提供跳转。

移动端保持纵向关系结构，并保证新增影视节点不会造成水平溢出。

### 企业服务能力

在集团首屏之后增加企业服务能力区，展示可以独立签约交付的三个事业群。避免三个等宽通用卡片，采用纵向能力索引或不等宽布局，通过排版和分隔关系表达：

- 高歌数字：软件产品、定制开发、系统集成、部署实施与维护。
- 高歌内容：平台运营、内容策划、图文生产、日常视觉和轻量短视频。
- 高歌影视：企业宣传片、品牌片、专业摄影、广告与自主影视作品开发。

高歌内容负责持续更新的日常内容，高歌影视负责以独立专业影像作品为主要交付物的项目。没有独立页面的高歌影视不提供伪链接。

### 高歌体育

高歌体育章节明确标注“非营利体育与球友社区”，并说明不承担商业收入目标。两个直属实体调整为：

- 高歌 FC：集团全资运营的非营利球队，参加业余联赛和友谊赛。
- 高歌超级联赛：高歌体育运营的球友内部联赛和社区赛事品牌，不作为商业赛事产品。

两个实体继续链接到高歌体育独立站点，并保留外链安全属性和明确的可访问名称。

### 联合交付

删除页面底部“持续生长中的新领域”，替换为“集团协同交付”：

- 客户可以直接向高歌数字、高歌内容或高歌影视采购。
- 同时涉及系统、内容和影像时，由高歌集团统筹联合交付。
- 高歌体育可以使用集团内部能力，但不作为企业商业交付板块。

该区块只表达合作关系，不展示虚构客户、收入数据或案例 Logo。

### 联赛董事会

保留当前 20 席高歌超级联赛董事会展示、静态数据和默认头像降级，不恢复已从集团页移除的六人管理团队模块。

## 数据与组件调整

### 首页领域类型

```ts
type CapabilityArea = 'digital' | 'content' | 'film' | 'sports'
```

`future` 被 `film` 替换。正式品牌页面的当前路由类型不增加 `film`，因为本次不创建影视页面。

### 集团事业群类型

```ts
interface GroupIndustry {
  readonly description: string
  readonly id: 'digital' | 'content' | 'film' | 'sports'
  readonly name: string
  readonly nature: string
}
```

移除不再使用的 `alias`、`href`、`target`、`status` 字段。星图只负责呈现集团直属关系。

### 新增组件

在 `apps/brand/src/pages/group/components/` 内新增页面私有组件：

- `BusinessCapabilities`：展示三个企业服务事业群及能力边界。
- `DeliveryModel`：展示独立采购、集团统筹和体育使用内部能力的关系。

组件不进入 `packages/*`，避免为单页结构提前抽象。

## 可访问性与响应式

- 首页新增影视信号必须使用语义化按钮，并打开与其他能力一致的原生弹窗。
- 首页四个信号在 320px、390px 和桌面宽度下不遮挡导航、主标题与正文。
- 集团星图在移动端保持中心到事业群的可读顺序，不依赖轨道图形理解关系。
- 无正式页面的高歌影视使用文本状态，不渲染无效链接。
- 外链继续使用 `target="_blank"` 和 `rel="noopener noreferrer"`。
- 所有新增动效服从现有 `prefers-reduced-motion` 规则。
- 保持现有暗色文字对比度、键盘焦点和 320px 最小宽度策略。

## 元信息

首页：

- 标题保持 `高歌 GAOGE - 享受你的热爱`。
- 描述更新为包含企业软件、内容运营、专业影像和非营利体育社区。

集团页：

- 标题保持 `高歌集团 - 组织与产业版图`。
- 描述更新为包含高歌数字、高歌内容、高歌影视、高歌体育及其组织关系。

## 验证

自动化测试覆盖：

1. 首页导航和能力弹窗展示数字、内容、影视、体育，不再展示未来。
2. 首页四个品牌信号分别打开正确的能力说明。
3. 首页元信息包含更新后的四个领域。
4. 集团星图包含四个确认事业群，不再展示小绿本和未来领域。
5. 集团页展示三个企业服务事业群的能力和联合交付关系。
6. 高歌体育非营利定位、高歌 FC 和高歌超级联赛说明准确。
7. 高歌体育两个实体外链安全属性正确。
8. 联赛董事会仍完整展示 20 席，不恢复管理团队。

工程验证：

```bash
pnpm --filter @gaoge/app-brand typecheck
pnpm --filter @gaoge/app-brand test
pnpm --filter @gaoge/app-brand build
```

浏览器检查：

- 首页 1440×900、390×844、320×800。
- 集团页 1440×900、768×1024、390×844、320×800。
- 首页四个信号、能力弹窗、Escape、焦点恢复与减少动态效果。
- 集团星图、企业服务区、体育结构、联合交付区和董事会完整性。
- 页面水平溢出、控制台错误、图片与视频降级。

## 知识库依据

本设计依据知识库实体 `kb:entity:gaoge-group` 中已经确认的集团定位、直属事业群、能力边界、体育非营利属性和当前不纳入架构范围。当前 `gaoge` 仓库缺少准确源码映射，因此页面实现细节继续以当前仓库源码和本设计为准。
