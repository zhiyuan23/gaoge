# Brand 首页角落导航微调设计

日期：2026-08-08

## 背景

Brand 首页在沉浸式滑雪影像上叠加顶部导航、英文主标题和四个能力入口。新增 `FILM / 专业影像` 后，桌面端 `SPORTS`、`FILM` 与 `your` 连续集中在右侧，右上区域的视觉重量略显拥挤。首页左上 Logo 内的字母 `G` 偏小，右上集团入口只有圆点，含义需要依赖悬停提示才能识别。

## 目标

- 放大左上 Logo 内的字母 `G`，并逆时针旋转 45 度。
- 为右上集团入口增加“集团”文字，同时保持低调的次级层级。
- 优化桌面端 `FILM` 的位置，利用右上暗部并减少与 `SPORTS` 的纵向堆叠。
- 保留现有首页视频、主标题、能力弹窗、导航结构和移动端四角构图。

## 设计方向

本次属于 Brand 首页的保留式微调，不改变既有视觉语言或信息架构。

- 设计变化度：8，延续不规则的品牌海报式构图。
- 动效强度：5，沿用现有悬停、按压与弹窗动效，不新增自动动画。
- 信息密度：3，新增“集团”文字仅用于消除入口歧义。
- 样式基础：继续使用项目现有 React、Tailwind CSS 与 Framer Motion，不引入新依赖或新设计系统。

## 具体设计

### 左上 Logo

- 保留现有圆形边框、24px 标记容器、`GAOGE` 字标、背景和点击区域。
- 将 `G` 从 11px 调整为 14px，使字母在圆形标记内更明确。
- 仅旋转字母本身，不旋转外部圆形边框。
- 使用 `transform: rotate(-45deg)` 表达逆时针 45 度旋转。
- 保留首页链接的可访问名称“高歌首页”。
- 该字形调整只应用于首页导航，数字、内容与集团页面的现有 Logo 样式不变。

### 右上集团入口

- 保留当前品牌强调色圆点，在其右侧增加“集团”文字。
- 将固定 36px 圆形按钮调整为高度 36px、内容自适应宽度的紧凑胶囊。
- 使用约 11px 字号、轻字重、较低白色透明度和轻微字距，使其低于中央能力导航与左侧品牌标识。
- 采用小间距和水平内边距，不增加阴影、发光或高对比实底。
- 悬停时仅轻微提高边框、背景和文字对比度，保留可见键盘焦点样式。
- 保留现有跳转目标 `/group` 和可访问名称“进入高歌集团”。

### FILM 位置

采用已确认的 B 方案“右上暗部内错位”。

- 移动端保持当前左上位置，继续与右上 `SPORTS`、左下 `DIGITAL`、右下 `CONTENT` 构成四角分布。
- 桌面端保留 `FILM` 在右上暗部，不移动到左侧或人物主体上。
- 桌面端从当前 `right: 5rem; top: 30%` 调整为 `right: 12%; top: 32%`。
- 该调整让 `FILM` 相对 `SPORTS` 明显向左错位并轻微下移，形成由 `SPORTS` 到 `FILM` 再到 `your` 的斜向节奏。
- 保留 `FILM / 专业影像` 的字号、斜线方向、点击区域、能力弹窗映射和焦点行为。

## 组件边界

- `BrandNavigation`：为首页渲染放大、旋转后的 Logo 字形，并调整首页集团入口的内容和样式；非首页 Logo 不变。
- `SkiingHero`：只调整 `FILM` 的桌面端定位类。
- `BrandSignal`、能力弹窗数据、路由和视频播放逻辑不改。
- 不把本次单页视觉调整抽取到共享包。

## 响应式与无障碍

- Logo 和集团入口在桌面、手机与 320px 最小宽度下都保持单行，不造成中央导航位移或水平溢出。
- 320-384px 手机上可继续隐藏 `GAOGE` 字标，但保留放大和旋转后的 `G`。
- 集团入口的交互高度保持 36px，现有 Header 区域提供足够的触控空间；不缩小当前可点击范围。
- 所有导航语义、焦点轮廓、能力按钮语义和减少动态效果偏好保持不变。

## 测试与验证

自动化测试补充或调整以下断言：

1. 首页 Logo 仍显示 `GAOGE`，且字母标记存在独立旋转元素。
2. 首页“进入高歌集团”链接显示“集团”文字并指向 `/group`。
3. `FILM` 仍是“打开影视能力说明”按钮，并打开影视能力弹窗。
4. 非首页导航与集团页当前状态不受影响。

实现完成后运行：

- `pnpm --filter @gaoge/app-brand typecheck`
- `pnpm --filter @gaoge/app-brand test`
- `pnpm --filter @gaoge/app-brand build`

视觉检查至少覆盖：

- 1440x900 桌面首屏，确认 `SPORTS`、`FILM`、`your` 不再形成拥挤直列。
- 390px 与 375px 手机首屏，确认四角能力入口、Logo 和集团入口无重叠。
- 320px 最小宽度，确认顶部导航无水平溢出。
- 减少动态效果偏好，确认海报降级和所有入口仍清晰可用。
- 浏览器控制台无新增错误。

## 不在本次范围

- 不修改背景视频、海报、主标题或首页正文。
- 不修改能力入口文案、能力弹窗内容或影视独立页面状态。
- 不调整中央“数字 / 内容 / 影视 / 体育”导航。
- 不修改 `/group` 页面或其他 Brand 矩阵页面。
- 不新增依赖、路由、接口或数据模型。
