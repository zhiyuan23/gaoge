# Gaoge Admin RBAC 内置数据精确同步设计

## 背景与根因

当前 Gaoge 源码只注册本项目的内置角色、资源、权限和菜单，但本地数据库仍保留此前同步写入的 `gaoge-compass` 与历史内置数据。现有 `RbacSyncService.syncBuiltIns()` 只对当前注册项执行 `upsert`，除单个废弃菜单外，不会回收已经离开当前注册表的内置数据。

已核对的本地数据库状态：

- 当前注册表：2 个角色、13 个资源、57 个权限、16 个菜单。
- 注册表外残留：2 个角色、47 个资源、178 个权限、95 个菜单。
- 残留均为 `isBuiltIn = true`。
- 当前没有自定义角色、资源、权限或菜单，也没有自定义菜单挂在残留内置菜单下、或自定义权限依赖残留资源。
- 两个残留角色没有关联用户。

## 目标

将内置 RBAC 同步从“只增改”调整为“以当前项目注册表为事实源的精确同步”：同步完成后，数据库中的内置角色、资源、权限和菜单集合与当前 Gaoge 注册表一致，不再保留其他项目或历史版本的内置条目。

## 方案

### 注册表边界

以下定义是当前项目内置数据的唯一事实源：

- `BUILT_IN_ROLE_DEFINITIONS`
- `BUILT_IN_RESOURCE_DEFINITIONS`
- `BUILT_IN_PERMISSION_DEFINITIONS`
- `BUILT_IN_MENU_DEFINITIONS`

只回收满足 `isBuiltIn = true` 且稳定标识不在对应当前注册表中的数据：

- Role 使用 `code`。
- Resource 使用 `key`。
- Permission 使用 `code`。
- Menu 使用 `routeName`。

任何 `isBuiltIn = false` 的自定义数据都不属于清理范围。

### 事务内同步顺序

同步继续在现有 Prisma 事务内执行，并按依赖关系处理：

1. Upsert 当前角色、资源、权限和菜单树。
2. 计算四类注册表外的残留内置记录。
3. 在删除菜单前检查是否存在非残留菜单挂在残留菜单下；存在时中止事务并返回明确错误，避免静默破坏自定义菜单树。
4. 按菜单树深度从叶子到根删除残留内置菜单；菜单权限和菜单资源关系通过现有级联关系清理。
5. 删除残留内置权限；角色权限和菜单权限关系通过现有级联关系清理。
6. 在删除资源前检查是否仍有非残留权限依赖残留资源；存在时中止事务，避免误删自定义权限依赖。
7. 删除残留内置资源。
8. 删除残留内置角色；用户角色关系和角色权限关系通过现有级联关系清理。当前残留角色没有关联用户，但实现不依赖这一数据库偶然状态。
9. 重建当前内置角色、菜单与当前权限/资源的关系。

所有步骤成功后统一提交；任一步失败则整个同步回滚。

### 返回结果

保留现有 `roles`、`resources`、`permissions`、`menus` 计数，避免破坏 Admin 现有调用契约。本次不新增清理统计字段，控制变更范围。

## 用户界面与运行结果

同步成功后，“菜单与权限”页面只展示当前 Gaoge 项目的用户权限、高歌体育和微信管理目录，以及对应的系统、足球、内容和微信权限资源。商品、订单、仓储、跨境财务、SaaS 等 Compass 条目从数据库和管理页面消失。

Admin 侧不增加隐藏或过滤规则；页面继续真实展示数据库中的项目 RBAC 数据。

## 错误处理与数据保护

- 清理条件必须同时包含 `isBuiltIn = true` 和“不在当前注册表”。
- 发现自定义菜单或权限依赖残留内置数据时，事务失败而不是自动改父级、停用或删除自定义数据。
- 不修改业务表、用户账号、当前项目权限码和当前项目菜单定义。
- 不触碰远程或生产数据库；本次只同步当前本地开发数据库。

## 测试与验证

1. 先补充失败测试，证明旧同步实现不会清理注册表外内置角色、资源、权限和菜单。
2. 覆盖残留数据清理、菜单叶子优先删除、仅清理 `isBuiltIn = true`、自定义依赖阻断和事务回滚语义。
3. 运行 RBAC 聚焦测试及 API 全量测试。
4. 运行 API/Admin typecheck 和生产构建。
5. 对本地数据库执行内置同步，复核内置集合精确等于 2/13/57/16。
6. 使用 admin 登录检查菜单与权限页面、侧边栏和浏览器控制台。

## 本次不做

- 不把业务注册表抽成跨项目共享包。
- 不增加前端项目识别或菜单过滤配置。
- 不修改当前 Gaoge 的足球、内容、微信或系统权限范围。
- 不清理用户创建的自定义 RBAC 数据。
- 不推送或部署到远程环境。
