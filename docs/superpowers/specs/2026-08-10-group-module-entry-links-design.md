# Group 模块入口与滚动复位设计

## 背景

Group 页的高歌数字与高歌内容模块需要提供进入各自正式能力页的入口。当前高歌内容使用整张展示卡片作为链接，交互范围过大；同时 React Router 在跨页面导航时保留原滚动量，导致目标页落在中段。

## 已确认方案

- 在“高歌数字”和“高歌内容”的标题行最右侧分别增加轻量入口。
- 入口可见文案为“进入数字”和“进入内容”，无障碍名称保留完整事业群名称。
- 入口使用 32px 高的深色幽灵按钮，弱边框、弱文字色和小号外跳箭头，不与模块标题争夺视觉焦点。
- 高歌内容卡片改为非交互 `article`，移除整卡跳转、箭头和交互位移。
- 在应用路由层按 `location.key` 记录页面离开前的滚动位置，并区分 React Router 导航类型。
- `PUSH` 与 `REPLACE` 跨页面导航同步滚动至 `{ left: 0, top: 0 }`，确保子页面从顶部打开。
- `POP` 导航恢复目标历史记录离开前的滚动位置；目标记录没有缓存时回到顶部。
- 同页 hash 章节切换不触发滚动复位，保留现有章节导航行为。

## 响应式与可访问性

- 标题和入口在桌面端、移动端均保持同一行，标题容器允许收缩，按钮禁止换行。
- 入口保留键盘焦点样式、悬停和按压反馈。
- 内容卡片不再暴露链接角色，也不再显示可点击指针或链接箭头。

## 验收标准

- Group 页可见两个独立的内部链接，分别指向 `/digital` 和 `/content`。
- 高歌内容展示卡片为 `ARTICLE`，卡片区域内不存在链接。
- 从 Group 页中段进入数字或内容页后，窗口滚动位置回到页面顶部。
- 从数字或内容页返回 Group 页后，窗口恢复到点击模块入口前的位置。
- 数字页与内容页之间的现有交叉导航同样回到顶部。
- 相关测试、格式检查、Lint、类型检查和构建通过，并完成桌面与移动端浏览器检查。
