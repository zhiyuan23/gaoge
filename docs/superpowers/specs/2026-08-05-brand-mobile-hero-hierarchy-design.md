# Brand 首页手机端首屏层级优化设计

日期：2026-08-05

## 背景

当前 Brand 首页在手机端同时使用两组醒目的白色英文：

- 中间主标题 `enjoy / your / passion`
- 三个角落能力入口 `SPORTS / DIGITAL / CONTENT`

两组文字在字号、字重、颜色和排版语言上较为接近，导致首屏缺少明确主次。手机端顶部同时存在“了解高歌”按钮，也与三个能力入口形成重复入口。

## 目标

- 让 `enjoy / your / passion` 成为手机端唯一的展示型大字。
- 将三个能力入口明确表现为次级、可点击的功能标签。
- 保留右上、左下、右下的三角构图和现有弹窗行为。
- 移除手机首页顶部的“了解高歌”按钮，减少重复入口。
- 桌面端现有构图与顶部导航不变。

## 设计方向

采用“角落能力标签”方案，属于对现有品牌语言的保留式优化。

设计参数：

- 设计变化度：8
- 动效强度：5
- 信息密度：3

页面继续保持沉浸式运动影像、高对比白色文字和不规则构图，不引入新的色彩体系或独立设计系统。

## 手机端排版层级

### 主标题

- `enjoy / your / passion` 保持现有分行和不规则位置。
- 手机端字号保持约 `15vw`，继续作为首屏唯一的展示型大字。
- 竖屏采用更清晰的下降对角节奏：`enjoy` 约位于左侧 `4vw / 22%`，`your` 约位于右侧 `4vw / 38%`，`passion` 约位于左侧 `10vw / 61%`。
- 正文约位于左侧 `24px / 49%`，落在 `your` 与 `passion` 之间并保留明确间距。
- 保持现有字体、白色和标题动效，不增加描边、渐变或玻璃背景。
- 手机横屏使用独立的低高度布局，维持相同阅读顺序，同时避免角标、正文和标题重叠。

### 三个能力入口

- 手机端继续放置在右上、左下、右下。
- 使用“短斜线 + 两层文字”的线性角标：英文在上、中文在下，延续桌面端原有品牌语言。
- 英文使用约 `12px` 的大写字形、较宽字距和中等字重。
- 中文使用约 `11px` 的次级文字，颜色低于英文层级。
- 短线长度约 `44-52px`、粗细 `1px`，使用低于正文的白色透明度；三个入口继续保留各自原有的斜线方向。
- 手机端不使用可见背景、边框、圆角、阴影或背景模糊。
- 每个按钮保持至少 `48px` 高的完整点击区域，并使用 `touch-action: manipulation`。
- 保留现有 `active:scale-[0.98]` 按压反馈、键盘焦点样式、弹窗映射和关闭后的焦点恢复。
- 不增加图标、编号、装饰圆点或额外自动动画。

### 顶部导航

- 手机首页移除居中的“了解高歌”按钮。
- 手机首页顶部只保留左侧 GAOGE 品牌标识。
- 桌面端“数字 / 内容 / 体育 / 未来”导航保持现有行为和样式。
- `/digital` 与 `/content` 等非首页路由的移动端当前领域标识不在本次范围内。

## 响应式边界

- `< 768px`：启用线性角标和重新分布的主标题位置。
- `>= 768px`：保留现有能力大字、斜线、字号、位置和桌面顶部导航。
- 低高度横屏补充条件必须限定在粗指针触控设备，避免改变桌面端缩短浏览器窗口时的布局。
- 在 375px、390px 手机宽度以及手机横屏下，不产生水平滚动或文字重叠。

## 组件调整

- `BrandSignal` 同时提供移动端线性角标和桌面端现有展示形态，两端复用同一个语义按钮和点击逻辑。
- `SkiingHero` 负责手机端位置和主标题字号调整，不改变能力入口与弹窗的映射关系。
- `BrandNavigation` 只移除首页移动端“了解高歌”入口，不改变已有弹窗实现和桌面导航。

## 无障碍与交互

- 三个能力入口继续使用原生 `button`。
- 保留现有可访问名称：
  - `打开体育能力说明`
  - `打开数字能力说明`
  - `打开内容能力说明`
- 点击区域不小于 48px 高，三个按钮之间不形成重叠点击区域。
- 保留可见的键盘焦点轮廓和按压反馈。
- 弹窗关闭后焦点返回原触发按钮。
- 尊重现有 `prefers-reduced-motion` 行为。

## 验证标准

1. 手机端首屏主标题明显高于三个能力入口的视觉层级。
2. 三个能力入口表现为无底色的“短斜线 + 两层文字”，不再像第二组主标题。
3. 手机端顶部不再出现“了解高歌”。
4. 三个入口分别打开体育、数字、内容弹窗，URL 不改变。
5. 关闭弹窗后焦点返回对应入口。
6. 每个移动端能力入口的点击区域高度至少为 48px。
7. 375px、390px 和横屏下无横向溢出、文字重叠或安全区遮挡。
8. 768px 及以上常规桌面布局的能力大字、斜线和顶部导航保持现状；低高度横屏规则不作用于非触控桌面设备。
9. Brand 测试、类型检查、构建、仓库 lint 和差异检查通过。

## 不在本次范围

- 不调整能力弹窗内容和玻璃材质。
- 不改变桌面端能力入口样式。
- 不改变品牌首页视频、海报或正文文案。
- 不新增路由、跳转或数据接口。
- 不调整非首页路由的移动端当前领域标识。
